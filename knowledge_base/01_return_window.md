# Nykaa Return Window Policy by Category

Nykaa provides a 15-day return window for unopened and sealed Beauty and Personal Care cosmetics from the date of delivery. Apparel and Footwear items are eligible for returns within 7 calendar days provided all original tags and shoe boxes are intact. Home and Wellness items can be returned within 10 days of delivery if untampered. Electronics and personal styling tools are non-returnable once opened, but carry manufacturer warranty support.
